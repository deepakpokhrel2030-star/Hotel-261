# Hotel261 Images By Room

Images are copied from `frontend/images/hotel261-labeled` and grouped by visible room or area.

- `single-room/` - single room photos
- `double-room/` - double room photos, including four-poster and red double room variants
- `twin-room/` - twin room photos
- `bathroom/` - bathroom and shower photos
- `room-details/` - towels, amenities, TV/mirror and close-up room detail photos

Use `../manifest.json` for the original numeric filename, descriptive label, and alt text.
